## BUG-0002

| Field | Value |
|-------|--------|
| **Title** | Manager can execute TL Verify and CA Verify — breaks review segregation of duties |
| **Severity** | Critical |
| **Priority** | P0 |
| **Status** | **VERIFIED** (2026-07-27) |
| **Steps** | 1. Login Manager. 2. List `status=READY_FOR_TL_VERIFY`. 3. `POST /items/{id}/verify/tl` `{decision:"pass"}`. 4. Immediately `POST /items/{id}/verify/ca` `{decision:"pass"}`. |
| **Expected** | Only TL (verify.tl) and CA (verify.ca) may pass those gates. Manager may close at end of chain, not perform TL/CA verify. Same actor cannot complete both TL and CA verify. |
| **Actual (original)** | Both calls return **200**. Manager alone advances `READY_FOR_TL_VERIFY` → `READY_FOR_CA_VERIFY` → `READY_FOR_MANAGER_CLOSE`. |
| **Screenshot** | N/A |
| **Video** | N/A |
| **API evidence (original)** | Work `019fa328-f695-796b-889f-4f107a83087b`: mgr TL verify 200; mgr CA verify 200. |
| **Database evidence (original)** | `wm_work_transitions` actor_id `WM-MGR-0001` on `verify_tl` / `verify_ca` actions (partner-gate works also show mgr as closer). |
| **Root Cause hypothesis** | Manager role granted `AllPermissions()` including `work.verify.tl` and `work.verify.ca`. Middleware accepts hierarchy-derived grants. |
| **Fix (Developer)** | Strip `work.verify.tl` / `work.verify.ca` from Manager defaults; hard-deny Manager on `VerifyTL`/`VerifyCA`; reject CA verify when actor is the same as the TL-pass verifier. Regression: `TestVerifyGates_SoD_ManagerAndSameActorCannotBoth`. |
| **API evidence (retest)** | Work `019fa391-9390-7b89-adac-96f97e925ee5`: Manager TL verify **403** `FORBIDDEN` `"insufficient work permissions"` (status stayed `READY_FOR_TL_VERIFY`); TL pass → Manager CA verify **403** (status stayed `READY_FOR_CA_VERIFY`); distinct CA pass → Manager close **200** `CLOSED`. Work `019fa391-93de-74a4-8163-196717a07db6`: Partner TL pass then same Partner CA **403** `"same actor cannot perform both TL and CA verify (segregation of duties)"`; distinct CA then Manager close **200**. |
| **Database evidence (retest)** | Work1 transitions: `verify_tl`=`WM-TL-0001`, `verify_ca`=`WM-CA-0001`, `close`=`WM-MGR-0001` (no mgr on verify gates). Work2: `verify_tl`=`USR-0003`, `verify_ca`=`WM-CA-0001`, `close`=`WM-MGR-0001`; no same-actor CA transition. |
| **Regression** | `TestVerifyGates_SoD_ManagerAndSameActorCannotBoth` PASS; `go test ./internal/workmgmt/...` PASS. |
