### Fix details

- **009** backfill heuristics: H0 assignee sync; H1 CA/TL from assigner/assignee roles (users + id prefixes); H2 engagement owner; H3 WM-* deterministic `WM-CA-((n-1)%20)+1` / `WM-TL-((n-1)%50)+1` from assignee digits.
- PRACTICE-* already had triad from `practiceuatseed` (500/500); left intact.
- New creates: CA actor → `ownerCaId`; TL actor → `tlId`; CA/TL assignee role fills the matching slot when empty.
