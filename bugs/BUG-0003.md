## BUG-0003

| Field | Value |
|-------|--------|
| **Title** | Intake approve / engagement create with invalid `clientId` returns HTTP 500 |
| **Severity** | High |
| **Priority** | P0 |
| **Status** | **VERIFIED** (2026-07-27) |
| **Steps** | 1. Manager creates intake. 2. `POST /intakes/{id}/approve` with `clientId:"CLI-DOES-NOT-EXIST"`. 3. Separately `POST /engagements` with `clientId:"CLI-0001"` (non-existent). |
| **Expected** | **400/404/422** validation or FK violation mapped to client error. |
| **Actual (original)** | **500 INTERNAL_ERROR** (`failed to approve intake` / `unexpected server error`). Valid `CLT-0046` paths succeed (200/201). |
| **Screenshot** | N/A |
| **Video** | N/A |
| **API evidence (original)** | `intake_approve_bad_client_not_500 → 500`; `engagement_bad_client_not_500 → 500`. First QA harness run: approve with `CLI-0001` → 500. |
| **Database evidence (original)** | FK `fk_wm_intake_client` / `fk_wm_eng_client` ON DELETE RESTRICT present (008). Violation bubbles as Internal. |
| **Root Cause hypothesis** | Postgres FK error not mapped to validation/conflict in `ApproveIntakeAtomic` / `CreateEngagement`. |
| **Fix (Developer)** | Map Postgres `23503` FK violations in `mapGateErr`/`mapFKViolation` to `BadRequest` (client/company/engagement). `ApproveIntake` and `CreateEngagement` return mapped AppError instead of Internal. Regression: `TestCreateEngagement_InvalidClientID_NotInternal`, `TestApproveIntake_InvalidClientID_NotInternal`. |
| **API evidence (retest)** | Intake `019fa396-59ef-7935-8d55-b6abc635040b`: approve with `CLI-DOES-NOT-EXIST` → **400** `BAD_REQUEST` `"invalid clientId: client not found"`. `POST /engagements` with `CLI-0001` → **400** same. Valid `CLT-0001`: approve intake **200** → eng `019fa396-5a06-7b13-9344-d51fdaab92e3`; create engagement **201** `019fa396-5a0e-71f8-8e29-aa437db33acb`. |
| **Regression** | `TestCreateEngagement_InvalidClientID_NotInternal` PASS; `TestApproveIntake_InvalidClientID_NotInternal` PASS; `go test ./internal/workmgmt/...` PASS. |
